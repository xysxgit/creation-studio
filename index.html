核心能力

🖼️

画板式创作

卡片 + 自由连线 + 编组分区。在无限画布上把人物、剧情、伏笔铺开、连接、梳理结构。

📚

多体裁剧本

面向小说、轻小说、RPG、Galgame、影视脚本，卷 / 章 / 卡片分层组织，随时切换。

✍️

富文本排版

内置专业富文本编辑器：标题、表格、图片、链接、高亮、下划线、颜色与字号自由设置。

🌐

局域网协同

同一局域网内多人实时共同创作，思维同步、实时连线、协作不冲突。

☁️

云端多版本备份

WebDAV 同步（坚果云 / Nextcloud / Box / AList 等预设），自动保留最近 30 份快照，可一键恢复任意版本。

🤖

AI 辅助创作

AI 替换 / 追加正文自动生成历史记录，可回退任意版本；修改前自动把原稿存进正文回收站，安全可找回。

📱

跨平台移动端（Capacitor）

基于 Capacitor 构建，一次开发多端运行，横竖屏自适应，触控友好，数据本地存储、离线可用。

🔒

数据安全

删除进回收站可恢复；正文自动备份；全程本地优先，你的作品始终在你手里。
